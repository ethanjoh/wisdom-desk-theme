# 티스토리 스킨 → 워드프레스 테마 변환 안내

업로드해주신 `skin.html` / `style.css`를 기반으로 워드프레스 테마를 만들었습니다.
디자인(레이아웃, 색상, 카드 UI, 반응형 서랍 사이드바 등)은 원본 CSS를 그대로 사용해 최대한 동일하게 유지했고,
티스토리 전용 템플릿 태그(`[##_xxx_##]`, `<s_xxx>`)는 워드프레스 루프/함수로 옮겼습니다.

## 설치 방법
1. 이 폴더 전체를 zip으로 압축된 상태 그대로 워드프레스 관리자 → 외모 → 테마 → 새로 추가 → 테마 업로드로 설치하거나,
   `wp-content/themes/` 폴더에 업로드하세요.
2. 외모 → 테마에서 활성화합니다.
3. 외모 → 메뉴에서 "상단 카테고리 메뉴(GNB)" 위치에 메뉴를 만들어 연결하세요. (메뉴를 만들지 않으면 카테고리 1뎁스/2뎁스가 자동으로 표시됩니다.)
4. 외모 → 위젯에서 "사이드바"에 태그 클라우드, 최근 댓글, 보관함(Archives), 달력 위젯 등을 자유롭게 배치하세요. 프로필/카테고리는 이미 사이드바 상단에 고정으로 출력됩니다.
5. 설정 → 읽기에서 "홈페이지 표시"를 원하는 방식으로 지정하세요.

## 파일 구성
- `style.css` — 테마 정보 + 원본 스킨 CSS 전체 (수정 없이 그대로 포함, 하단에 워드프레스 호환용 CSS 소량 추가)
- `functions.php` — 테마 설정, 위젯 영역, 메뉴, 썸네일 크기, 헬퍼 함수
- `header.php` / `footer.php` — 헤더(로고, 검색, GNB, 배너 영역 자리) / 푸터
- `sidebar.php` — 프로필 카드 + 카테고리 트리 + 위젯 영역
- `index.php` — 블로그 목록(카드형 리스트)
- `archive.php` — 카테고리/태그/날짜 아카이브
- `search.php` — 검색결과
- `single.php` — 글 상세 (해당 카테고리 최신글 사이드 위젯, 태그, 관련글, 댓글 포함)
- `page.php` — 고정 페이지
- `comments.php` — 댓글 목록/작성 폼
- `404.php` — 404 페이지
- `inc/class-tistory-style-nav-walker.php` — 스킨 CSS가 기대하는 `category_list / sub_category_list` 마크업으로 워드프레스 메뉴를 출력하는 커스텀 워커
- `js/theme.js` — 모바일 서랍 사이드바 토글, 메가메뉴 높이 계산 등 원본 jQuery 스크립트를 바닐라 JS로 재작성

## 그대로 옮기지 못한(또는 방식이 달라진) 티스토리 전용 기능
- **애드센스/수익 위젯 영역** (`[##_revenue_list_upper_##]`, `[##_revenue_list_lower_##]`) — 워드프레스에는 대응 기능이 없어 제거했습니다. 광고를 넣으려면 `header.php`/`footer.php`에 직접 코드를 추가하거나 광고 플러그인을 사용하세요.
- **Tiara 클릭 로깅 속성**(`data-tiara-*`) — 카카오 내부 분석 도구라 제거했습니다. 필요하면 Google Analytics 등으로 대체하세요.
- **방문자수 카운터** (`[##_count_total_##]` 등) — 워드프레스 기본 기능이 아니라 제거했습니다. 필요하면 통계 플러그인(예: WP Statistics)을 설치해 위젯으로 추가하세요.
- **방명록 / 위치로그(Local Log)** — 티스토리 고유 기능이라 제외했습니다.
- **보호글(비밀번호 글)** — 대신 워드프레스 기본 "비밀번호 보호 게시물" 기능을 사용하세요(글 작성 시 공개 범위에서 선택).
- **홈 화면의 뉴스 헤드라인/2열 카테고리 커버, 카테고리별 최신글 사이드 위젯** — 원본은 자바스크립트로 현재 페이지 HTML을 긁어와 재조립하는 방식이었는데, 워드프레스에서는 `single.php`의 "해당 카테고리 최신글" 위젯처럼 서버에서 바로 쿼리로 뽑아오도록 다시 구현했습니다. 홈 화면 커버 섹션이 필요하면 말씀해 주시면 추가로 만들어 드릴게요.
- **Mermaid 다이어그램 자동 렌더링 스크립트** — 필요하시면 별도 플러그인(예: WP Mermaid)을 쓰시는 걸 권장하며, 포함하지 않았습니다.

## 커스터마이징 팁
- 로고: 외모 → 사용자 정의하기 → 사이트 아이덴티티에서 로고 이미지를 올리면 헤더에 반영됩니다.
- 배너 이미지: `header.php`의 `area-align` 아래에 원하는 배너 마크업(`area-promotion`)을 추가하면 됩니다.
- 카드 목록의 요약문 길이는 `functions.php`의 `tistory_style_excerpt_length()`에서 조절할 수 있습니다.
